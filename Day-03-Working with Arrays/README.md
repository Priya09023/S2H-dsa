# 📅 Day-03: Working with Arrays

## 📖 Introduction to Arrays

Arrays are one of the most fundamental and widely used data structures in programming.

An **array** is a collection of elements stored in **contiguous memory locations**, where each element can be accessed using an **index**.

### 🔹 Key Characteristics

* Elements are stored in **continuous memory**
* Indexing starts from **0**
* Allows **fast access (O(1))**
* Same type of elements are stored



## 🎯 Why Arrays are Important?

Arrays form the base for many advanced data structures like:

* Strings
* Matrices
* Heaps
* Hashing

They are heavily used in:

* Searching algorithms
* Sorting techniques
* Optimization problems



## 💡 Types of Problems in Arrays

While solving array problems, we mainly deal with:

* Traversal (looping through elements)
* Finding max/min values
* Rearranging elements
* Searching and sorting
* Subarray problems

## 📚 Problems Covered

### 1. Find the Largest Element in an Array

Find the maximum element present in the array.



### 2. Find Second Smallest and Second Largest Element

Find second smallest and second largest elements. Return -1 if not possible.



### 3. Check if Array is Sorted

Check whether the given array is in ascending order or not.



### 4. Remove Duplicates from Sorted Array

Remove duplicates in-place and keep only unique elements.



### 5. Left Rotate Array by One

Shift all elements to left by one position.



### 6. Rotate Array by K Elements

Rotate array either left or right by k steps.



### 7. Move All Zeros to End

Move all zero elements to the end while maintaining order.



### 8. Union of Two Sorted Arrays

Find union of two sorted arrays without duplicates.



### 9. Maximum Consecutive Ones

Find the maximum number of consecutive 1’s in the array.



### 10. Find Single Number

Find the element that appears only once while others appear twice.

## ⚙️ Complexity Understanding

* Accessing element → O(1)
* Traversing array → O(n)
* Searching → O(n) (linear search)



## 🚀 Learning Approach

* Start with simple traversal problems
* Understand patterns like rotation and shifting
* Practice optimization techniques
* Focus on edge cases
