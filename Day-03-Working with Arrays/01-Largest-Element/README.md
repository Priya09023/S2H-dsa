## Find the Largest Element in an Array

### Practice Link
https://www.geeksforgeeks.org/find-largest-element-in-an-array/

### Description
In this program, I found the largest element present in the given array.

### Concept
The main idea is to compare all elements in the array one by one.

A variable is used to store the current largest value.

If a bigger element is found while traversing the array, the largest value is updated.

### Program Explanation
The program takes array elements as input.

Initially, the first element is considered as the largest element.

Then the program checks the remaining elements one by one.

If any element is greater than the current largest element, it gets updated.

After checking all elements, the final largest value is printed.

For example:

Array = [2, 5, 1, 3, 0]

Here, 5 is greater than all other elements, so output is 5.

### Output
5

### Conclusion
By comparing all elements in the array, we can easily find the largest element in a simple way.
