# 01. Find Largest Element in an Array

## 🔗 Practice Link

https://www.geeksforgeeks.org/find-largest-element-in-an-array/


## 🧩 Problem Statement

Given an array of integers, find the largest element present in the array.



## 📌 Example

**Input:**
5
2 5 1 3 0

**Output:**
5


## 📖 Explanation

* Traverse the array and compare elements
* Keep track of the maximum value found so far
* Final value will be the largest element



## 💡 Approach

* Initialize max with first element
* Compare each element with max
* Update max if a larger element is found



## ⚙️ Algorithm

1. Read array size and elements
2. Initialize max = first element
3. Traverse the array
4. If current element > max → update max
5. Print max



## ⏱️ Complexity

* **Time Complexity:** O(n)
* **Space Complexity:** O(1)



## 🚀 Key Points

* Simple traversal problem
* No extra space required
* Important basic concept
