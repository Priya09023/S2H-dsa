# 05. Left Rotate Array by One

## 🔗 Practice Link

https://leetcode.com/problems/rotate-array/description/


## 🧩 Problem Statement

Given an array, rotate the elements to the left by one position.



## 📌 Example

**Input:**
1 2 3 4 5

**Output:**
2 3 4 5 1



## 📖 Explanation

* The first element moves to the end
* All other elements shift one position to the left



## 💡 Approach

* Store the first element
* Shift all elements one step left
* Place the first element at the end



## ⚙️ Algorithm

1. Store first element
2. Shift elements from left to right
3. Assign first element to last position
4. Print array



## ⏱️ Complexity

* **Time Complexity:** O(n)
* **Space Complexity:** O(1)



## 🚀 Key Points

* In-place operation
* No extra space required
* Basic rotation concept
