# 09. Sort a String in Alphabetical Order

## 🔗 Practice Link

https://www.geeksforgeeks.org/program-to-sort-a-string-of-characters/


## 🧩 Problem Statement

Given a string `s`, sort its characters in alphabetical order.



## 📌 Example

**Input:**
s = "aditya"

**Output:**
aadity



## 📖 Explanation

* Rearrange characters of the string in increasing alphabetical order
* Duplicate characters should also be included



## 💡 Approach

* Convert string into character array
* Sort the characters
* Convert back to string



## ⚙️ Algorithm

1. Take input string
2. Convert to character array
3. Sort the array
4. Convert back to string
5. Print result



## ⏱️ Complexity

* **Time Complexity:** O(n log n)
* **Space Complexity:** O(n)



## 🚀 Key Points

* Sorting helps in many string problems
* Built-in sorting functions make it easy
* Useful in anagram and pattern problems
