## Sort a String in Alphabetical Order

### Practice Link
https://www.geeksforgeeks.org/program-to-sort-a-string-of-characters/

### Description
In this program, I sorted the characters of a string in alphabetical order.

### Concept
The main idea is to compare characters in the string and arrange them in ascending alphabetical order.

If one character is greater than another character, their positions are swapped.

This process continues until all characters are arranged properly.

### Program Explanation
The program takes a string as input.

It compares each character with the remaining characters in the string.

Whenever a smaller character is found, swapping is performed.

After completing all comparisons, the characters become sorted in alphabetical order.

For example, if the input string is "aditya":

After sorting the characters alphabetically, the string becomes "aadity".

### Output
Given string in alphabetical order is : aadity

### Conclusion
By comparing and swapping characters, we can sort a string in alphabetical order in a simple way.
